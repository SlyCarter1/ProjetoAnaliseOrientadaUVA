Módulo 1 — Introdução à Programação

Aula 1: O que é programação?

Entenda o que significa programar e como a tecnologia utiliza instruções para realizar tarefas.

1. O que é programação?

Programação é o processo de criar instruções para que um computador execute determinadas tarefas. Essas instruções são escritas utilizando linguagens de programação.

Por exemplo, quando você utiliza um aplicativo de mensagens, existe um conjunto de códigos responsável por enviar, receber e organizar as mensagens.

2. Como funciona?

O computador não entende nossas intenções sozinho. Precisamos fornecer instruções claras e organizadas para que ele saiba o que fazer.

Podemos comparar a programação com uma receita: cada etapa precisa ser seguida na ordem correta para chegar ao resultado esperado.

3. O que é uma linguagem de programação?

É uma linguagem utilizada para escrever instruções que podem ser interpretadas ou executadas pelo computador.

Alguns exemplos são:

  • Python
  • Java
  • JavaScript
  • C

4. Exemplo prático

Observe este pequeno código em Python:

print("Olá, mundo!")

Esse comando faz o computador exibir a mensagem "Olá, mundo!" na tela.

5. Resumo da aula

Programar significa criar instruções para que computadores realizem tarefas. As linguagens de programação permitem que essas instruções sejam escritas de maneira organizada.
